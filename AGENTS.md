# AGENTS.md

## Repository

- Dette er Finnmarkspanelet-prosjektet (`kwengen/finnmarkspanelet`).
- Arbeid på `main` som standard.

## Git-arbeidsflyt

- Når en oppgave innebærer endringer, skal de som standard committes og pushes til `main`.
- Dersom brukeren ber om en annen gren, pull request, ingen push eller en annen GitHub-arbeidsflyt, skal det valget overstyre standarden.
- Før push skal arbeidsstatus, aktiv gren og remote kontrolleres, og relevante tester eller kvalitetssjekker kjøres.
- Ikke ta med eksisterende, urelaterte brukerendringer i committen.
- Ikke push hemmeligheter, miljøfiler eller midlertidige artefakter.
